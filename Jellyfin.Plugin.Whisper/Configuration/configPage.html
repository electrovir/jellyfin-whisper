Whisper Transcription Settings

Path to the whisper-cpp binary. Default: "whisper-cpp" (on PATH via homebrew).
Path to ffmpeg for audio extraction. Default: "ffmpeg" (on PATH).
Model name or path passed to whisper-cpp's --model flag. Default: "medium".

EDL Mute Settings

Words or phrases to mute via EDL files. One per line. Case-insensitive. Punctuation is stripped when matching against whisper tokens. Multi-word phrases are matched against consecutive tokens.
Milliseconds of buffer added before and after each muted word. Ensures the word is fully covered even if token timing is slightly off. Default: 150.

Actions

Regenerate All EDL Files re-creates EDL mute files from existing transcriptions using the current word list. Fast — does not re-run whisper.
Reset All Transcriptions wipes all ".complete" markers so every media file will be re-transcribed on the next scheduled task run.
