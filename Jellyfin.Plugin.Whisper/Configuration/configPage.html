Whisper Transcription Settings

Full path to the whisper-cli binary.
Path to ffmpeg for audio extraction.
Full file path to a downloaded .bin model file (e.g. /Users/media/ggml-medium.bin).
Makes mute timing much more accurate. Auto works for model files with their original names (e.g. ggml-medium.bin is "medium"). For a renamed model, pick the preset matching it. Only affects newly transcribed files.

EDL Mute Settings

Words or phrases to mute via EDL files. One per line. Case-insensitive. Punctuation is stripped when matching against whisper tokens. Multi-word phrases are matched against consecutive tokens.
Milliseconds of buffer added before and after each muted word. Default: 150.

Actions

Regenerate All EDL Files re-creates EDL mute files from existing transcriptions using the current word list. Does not re-run whisper. Filtered audio tracks in media files will be re-created in the background, which may take a while for large libraries.
Reset All Transcriptions wipes all ".complete" markers so every media file will be re-transcribed on the next scheduled task run.
